# 基隆土地查詢與建案評估

- [開啟 v3 評估系統](https://swentsan.github.io/keelung-land-use-checker/v3/)
- [基隆專用查詢服務](https://keelung-assessment-api.masmorning.chatgpt.site/)
- [既有簡易查詢頁](https://swentsan.github.io/keelung-land-use-checker/)（保留原版）

v3 已接上公開雲端後端，可輸入一筆或多筆地號，自動讀取官方分區、逐街廓配對土管、套繪地籍及道路，並試算有依據的退縮候選範圍。外地電腦直接開啟 v3 網址即可，不需要本機服務、上傳資料或登入。

`v3/` 是 GitHub Pages 前端；`cloud/` 是雲端 Worker 原始碼；`app/` 保留原本 Python 版與其他主機部署方式。詳見 [發布與使用](docs/發布與使用.md)。

規則庫核對日 2026-11-03，57 組含數值計畫、408 筆數值規則、64 個圖台細計範圍。2026-11-04 實測大德段615、八德段663-96、代天府段132-1。未知數值保留待核對，候選包絡不等於正式可建範圍；機關用地不代表可作一般住宅銷售。

即時查詢仍受官方圖台可用性影響。公開內容只含程式及官方規則資料，不儲存私人個案、財務草稿或憑證。
