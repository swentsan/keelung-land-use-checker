# 基隆評估 v3 發布狀態

- GitHub Pages 的 `/v3/` 提供土管規則庫、逐計畫條文、完整財務試算。
- 原本首頁保留，v3 程式位於 `app/`，公開規則資料來自基隆市官方公告。
- 即時地號查詢、官方表單讀取與地籍套繪需要 Python 查詢後端。GitHub Pages 不執行 Python，因此在後端啟用前，v3 的查詢按鈕會停用並顯示狀態。
- 不會拿預存的 615 結果冒充即時查詢。

## 部署查詢後端

`render.yaml` 是待部署設定，不表示已有線上服務。透過 Render 帳號連接此 GitHub repository，建立 Blueprint 後才能啟用。設定使用 free 方案；實際可用資格及條件依服務商為準，不會由此檔案自行購買方案。

其他支援 Python 的主機也可執行：

```sh
python app/hosted_server.py
```

環境變數：

- `PORT`：主機指定的監聽埠，預設 8766。
- `ALLOWED_HOSTS`：允許的服務 hostname，以逗號分隔。Render 會自動讀取 `RENDER_EXTERNAL_HOSTNAME`；其他主機必須設定此值。
- `ALLOWED_ORIGINS`：允許呼叫 API 的網頁 origin，預設 `https://swentsan.github.io`，不用加入 repository 子路徑。

先確認公開 `https://實際服務網址/api/health` 回傳 `{"ok":true,"version":"3.0"}`，再將 `v3/api-config.js` 的 `window.KEELUNG_API_BASE` 改為實際 HTTPS 服務 origin（沒有尾端斜線）。提交到 main 後，GitHub Actions 會更新網頁。

僅在部署前端與 Python v3 後端相容時設定網址；既有的簡易分區查詢 API 回傳格式不同，不能直接替換。

## 地號測試

先輸入 `中山區／大德段／615`。再測試 `暖暖區／八德段／663-96`、`中山區／代天府段／132-1`，核對行政區、計畫號、建蔽容積、道路及退縮條件。

公開資料查詢仍可能受官方站台中斷影響。未確認的條件保留待核對；候選包絡不等於正式建築線或正式可建範圍。B0069 不因圖台標題而套用 388，須以實際發布範圍裁切。

## 本機使用

保留原本的 loopback 入口 `python app/auto_server.py`，以 `http://127.0.0.1:8766/` 使用，不必更改原有 NAS 啟動方式。
