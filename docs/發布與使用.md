# 基隆評估 v3 發布與使用

2026-11-04 已啟用公開雲端查詢服務。

- 分享網址：https://swentsan.github.io/keelung-land-use-checker/v3/
- 查詢服務：https://keelung-assessment-api.masmorning.chatgpt.site/
- 健康檢查：查詢服務網址後加 `/api/health`，應回傳 `ok:true`、`version:3.0`。

直接在 v3 網頁輸入行政區、地段／小段全名、地號。多筆同段可用換行或逗號；跨段每行輸入「中山區,大德段,615」，每次最多10筆。無須上傳或執行本機程式。

查詢服務只接受固定的官方資料路徑，不提供任意網址代理或資料寫入。GitHub 網頁來源已列入跨來源存取許可。財務草稿保存在使用者瀏覽器，不會送到查詢服務。

雲端來源為 `cloud/`，建置與10項引擎檢查命令：

```sh
cd cloud
node --test tests/engine.test.mjs
node scripts/build.mjs
node scripts/validate-artifact.mjs
```

Sites 專案 ID 保存在 `cloud/.openai/hosting.json`，更新時應沿用，勿建立重複專案。發布仍須透過有權限的帳號同步原始碼及部署；原始碼不含權杖。

本次外部實測：大德段615為計畫105、50%／250%；八德段663-96為計畫282、40%／120%、全界退縮10m候選面積約2837.22㎡；代天府段132-1維持案380、數值待核對，不誤套獅球嶺388。

`app/` Python 版與 `render.yaml` 僅作替代主機部署，不是目前的雲端服務。若需本機使用可執行 `python app/auto_server.py`，再開啟 `http://127.0.0.1:8766/`。

官方服務中斷會顯示失敗，不以預存測試結果冒充即時回應。未確認的條件保留待核對；候選包絡不等於正式建築線或正式可建範圍。
